# Чи вистачить заряду?

Статичний сайт без залежностей і збірки. Працює на GitHub Pages і при відкритті `index.html` подвійним кліком.

## Публікація на GitHub Pages
1. Створіть репозиторій і завантажте вміст цієї папки в корінь (`index.html` має лежати в корені).
2. Settings → Pages → Source: «Deploy from a branch», гілка `main`, папка `/ (root)`.
3. За хвилину сайт буде за адресою `https://<ваш-логін>.github.io/<репозиторій>/`.
